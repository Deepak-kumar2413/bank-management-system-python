# 🏦 Bank Management System

### 💻 Python Mini Project | Object-Oriented Programming (OOP)

A simple and beginner-friendly **Bank Management System** developed using Python. This project demonstrates basic banking operations using Object-Oriented Programming concepts.

---

## 📌 About the Project

The Bank Management System is a console-based Python application that allows users to create and manage multiple bank accounts, deposit money, withdraw funds, transfer money between accounts, and track transaction history.

This project is designed to practice Python programming and OOP concepts.

## ✨ Features

- ✅ Create New Bank Accounts
- ✅ Deposit Money
- ✅ Withdraw Money
- ✅ Transfer Money Between Accounts
- ✅ View Transaction History
- ✅ Check Account Balance
- ✅ Display All Accounts
- ✅ Exit the Application

## 🛠️ Technologies Used

- **Language:** Python 3
- **Programming Paradigm:** Object-Oriented Programming (OOP)
- **Interface:** Command Line Interface (CLI)
- **Data Storage:** Python Dictionary and List

## 🚀 How to Run

**Step 1:** Install Python 3.

**Step 2:** Clone the repository.

```bash
git clone https://github.com/Deepak-kumar2413/bank-management-system-python.git
```

**Step 3:** Open the project folder.

```bash
cd bank-management-system-python
```

**Step 4:** Run the Python program.

```bash
python main.py
```
